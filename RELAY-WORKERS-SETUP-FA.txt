راهنمای استقرار Relay هویت BEE-VPN (رفع مشکل «در حال اتصال» روی اپراتورهای فیلترشده)
====================================================================================

چرا این راهنما؟
---------------
اپ برای ساختن هویت WARP دو مسیر دارد:
  ۱) مسیر مستقیم: ثبت‌نام روی api.cloudflareclient.com از خود گوشی.
  ۲) مسیر Relay: دو Cloudflare Worker که ثبت‌نام را از شبکهٔ کلادفلر انجام می‌دهند.

روی بعضی اپراتورها مسیر مستقیم فیلتر یا کند است؛ مسیر Relay دقیقاً برای همین ساخته
شده است. از نسخهٔ 3.2.1 اگر Relay پیکربندی نشده باشد، اپ به‌جای معطل‌شدن روی
Workerهای خالی، مستقیم سراغ مسیر مستقیم می‌رود (رفع تاخیر ~۹۰ ثانیه‌ای «در حال اتصال»).

بستهٔ آماده: docs/relay-worker.js
--------------------------------
فایل وورکر کامل در ریپازیتوری هست. هر دو Worker (A و B) همین یک فایل را دارند.

مراحل استقرار (حدود ۱۰ دقیقه)
------------------------------
۱) یک رمز مخفی بسازید؛ مثلا در ترمینال:
     openssl rand -hex 32
   مقدار را جایی ذخیره کنید — در سه جا استفاده می‌شود (Worker A، Worker B و گیت‌هاب).

۲) docs/relay-worker.js را باز کنید و مقدار SECRET را با همان رمز عوض کنید.

۳) وارد dash.cloudflare.com شوید → Workers & Pages → Create application → Worker
   → Create Worker. نام: beehive-relay-a (یا هر نامی). کد پیش‌فرض را پاک کنید و
   محتوای docs/relay-worker.js را بچسبانید → Deploy.
   آدرس Worker را کپی کنید؛ شکلی مثل:
     https://beehive-relay-a.<نام-حساب شما>.workers.dev

۴) یک Worker دوم با نام دیگر (مثلا beehive-relay-b) و همان کد بسازید.

۵) تست سریع سلامت (بدون امضا باید ۴۰۱ بدهد، نه ۵۰۲):
     curl -i -X POST "https://<worker-a>....workers.dev/v0a4471/reg" -d '{}'
   پاسخ {"error":"bad signature"} یا {"error":"stale timestamp"} = وورکر سالم است.

۶) در ریپازیتوری گیت‌هاب: Settings → Secrets and variables → Actions → New repository
   secret — سه مقدار را اضافه کنید:
     BEE_IDENTITY_RELAY_HMAC = رمز مخفی مرحلهٔ ۱
     BEE_RELAY_A             = آدرس وورکر A
     BEE_RELAY_B             = آدرس وورکر B

۷) ورک‌فلو Release را دوباره اجرا کنید (تگ جدید بزنید یا از تب Actions دوباره
   اجرا کنید). در APK جدید، مسیر Relay فعال است و ثبت‌نام از شبکهٔ کلادفلر انجام
   می‌شود.

نکته‌های امنیتی
---------------
* رمز فقط پیش‌دانستهٔ اپ و Worker است؛ هرکس Worker را پیدا کند بدون امضای معتبر
  (۴۰۳) بلاک می‌شود. Timestamp و Nonce جلوی حملهٔ replay را می‌گیرند.
* اگر خواستید رمز را عوض کنید: هم در هر دو Worker و هم در Secret گیت‌هاب، سپس
  Release دوباره.
* Worker روی پلن رایگان کلادفلر کاملاً کافی است (محدودیت ۱۰۰هزار درخواست/روز).

اگر Relay را مستقر نکردید چه؟
-----------------------------
اپ همان‌طور که هست کار می‌کند: مسیر مستقیم + مسیرهای درون‌اپ (Warp Setting →
GET IDENTITY با روش Shard یا Plain که رجیستری را از مسیر رمزگذاری‌شدهٔ ECH یا
نودهای SHARD انجام می‌دهند). Relay فقط پشتیبانِ قوی‌تر برای اپراتورهای سخت‌گیر است.
