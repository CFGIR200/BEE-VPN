# BEE-VPN برای iOS — هم‌ترازِ برنامهٔ اندروید

همان اشتراک، همان سرور لایسنس، همان ظاهر عسلی، همان رشته‌های فارسی — این بار بومی SwiftUI.

این نسخه یک **کپی ساختاریافتهٔ برنامهٔ اندروید** است: کاتالوگ رشته‌ها (۸۱۵ رشتهٔ en/fa) عیناً از
`Strings.kt` اندروید پورت شده، فایل `geoip-iran.cidr` عیناً همان asset اندروید است، و صفحه‌ها
طبق همان نقشهٔ اندروید ساخته شده‌اند.

| تونل WARP (ثبت‌نام بومی در api.cloudflareclient.com) | ✅ کامل |
| تنظیمات چندبخشی (PROTECTION / ROUTING & DATA / CONNECTION / APPEARANCE / BACKUP / ABOUT) | ✅ کامل |

## معماری

```
ios/
├── project.yml                 # XcodeGen — دو تارگت، نسخهٔ 3.6.10 (471)
├── Scripts/
│   ├── gen-config.sh           # تزریق URL لایسنس و کلید عمومی از secrets
│   └── prepare-wireguard.sh    # کلون وایرگارد-اپل 1.0.16-27 + ساخت پل Go
├── BEE-VPN/                    # تارگت اپ (app.beevpn)
│   ├── App/                    # BeeApp، Theme (پالت روشن/تاریک)، Strings (۸۱۵+۸۶)، AppState (پروفایل‌ها/لاگ)
│   ├── Net/Routing.swift       # مکمل CIDR: دور زدن ایران + LAN → AllowedIPs
│   ├── VPN/TunnelController.swift  # نردبان پورت + تأیید ترافیک + اتصال مجدد خودکار
│   ├── Warp/WarpProvisioner.swift  # ثبت‌نام WARP + wg-quick
│   ├── License/                # Ed25519 (CryptoKit)، Keychain، API لایسنس
│   ├── Views/                  # Home، Mode، Settings، TunnelControls، WarpSetting،
│   │                           # Logs، TrafficMonitor، Subscription، Gate، Advanced
│   └── Resources/geoip-iran.cidr   # عیناً همان asset اندروید (۲٬۲۳۵ محدوده)
└── BeeTunnel/                  # تارگت NetworkExtension (app.beevpn.tunnel)
    └── PacketTunnelProvider.swift  # WireGuardAdapter + لاگ به کانتینر مشترک
```

## بیلد

**مسیر ۱ (پیشنهادی) — GitHub Actions:** روی هر پوشِ مسیر `ios/**` ورک‌فلوی `iOS build`
یک IPA بدون امضا می‌سازد و به آرتیفکت `BEE-VPN-unsigned-ipa` می‌گذارد. سکرت‌های لازم:

- `BEE_LICENSE_URL` — آدرس Worker لایسنس
- `BEE_LICENSE_PUBKEY_B64` — کلید عمومی Ed25519 (همان مقدار `/pubkey`)
- `BEE_TELEGRAM_URL` و `BEE_SUPPORT_URL` (اختیاری — پیش‌فرض همان کانال‌ها)

**مسیر ۲ — مک شخصی:**

```bash
brew install xcodegen go
./Scripts/prepare-wireguard.sh   # ../wireguard-apple + out/libwg-go.a
xcodegen generate
open BEE-VPN.xcodeproj
```

## نصب IPA بدون امضا

- **Sideloadly / AltStore** با Apple ID شخصی (امضای ۷ روزه) — entitlement
  packet-tunnel-provider و app group با تیم شخصی در حالت توسعه پشتیبانی می‌شود.
- **TrollStore / ESign** روی نسخه‌های پشتیبانیشده.
- برای TestFlight/App Store به حساب $۹۹ اپل و تیم واقعی نیاز است (اپ‌های VPN بازبینی
  ویژه دارند).

## نکته‌ها

- هر اشتراک فقط به یک دستگاه بسته می‌شود — کد اندرویدی را روی iOS فعال نکن؛ برای انتقال از
  پشتیبانی بخواه (همان قاعدهٔ Worker).
- اگر UDP 2408 بسته بود: اسکن خودکار خودش روی 500/1701/4500 می‌رود، یا نقطهٔ دستی بده.
- سرویس لایسنس و ربات تلگرام تغییری نکرده‌اند — iOS همان `/activate` `/login` `/verify` را صدا می‌زند.
- حریم خصوصی: فقط کد اشتراک و شناسهٔ دستگاه به سرور لایسنس می‌رود؛ ترافیک کاربر داخل تونل WARP.
- رشته‌های zh در اندروید وجود دارند ولی انتخابگر زبان فقط انگلیسی/فارسی می‌دهد؛ طبق همان رفتار،
  کاتالوگ iOS هم en/fa است.
